# 更新日志

APS Design Pro 以语义化版本（SemVer）发布，源码与标签托管于 Gitee。本页记录当前版本与后续规划。

## 当前版本

`0.3.1` 是当前发布版本，已对齐官网依赖。本版本聚焦于持续维护与组件能力补齐，可在[组件目录](/components)查看全部公开组件。

完整的历史发布记录（含每个标签的变更明细）以 Gitee 仓库的 Tags 为准：

- 源码与标签：[xhyym/aps-design-pro](https://gitee.com/xhyym/aps-design-pro)
- 组件问题反馈：通过 Gitee Issue 提交

## Roadmap

以下为面向后续版本的规划方向，具体以实际发布为准：

- **组件覆盖**：继续补齐布局与图表类能力，覆盖更多中后台常见工作流。
- **无障碍**：增强键盘可达性与 ARIA 语义，提升读屏与键盘操作体验。
- **工程化**：推进 SSR 兼容与产物体积优化，降低大型后台的接入成本。
- **主题系统**：丰富设计令牌与暗色模式表现，支持更细粒度的品牌定制。

欢迎通过 Gitee Issue 或[共建名单](/contributors)参与讨论与贡献。
