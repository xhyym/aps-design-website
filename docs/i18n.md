# 国际化

APS Design Pro 把"文案"分成两层：组件**内置**的可复用文案（如日期选择器、分页器）由库自身管理；**业务**文案（字段名、按钮、提示）由你的应用管理。这种拆分让组件保持独立，不与具体业务语言耦合。

## 组件内置语言

组件库内置两种语言：`zh-CN` 与 `en-US`，默认 `zh-CN`。通过 `AppConfigProvider` 的 `locale` 属性统一控制所有后代组件的内置文案：

```vue
<script setup lang="ts">
import { ref } from "vue";
import { AppConfigProvider } from "aps-design-pro";

const locale = ref<"zh-CN" | "en-US">("zh-CN");
</script>

<template>
  <AppConfigProvider :locale="locale">
    <!-- 内部含日期、分页等内置文案的组件会随 locale 切换 -->
    <AppDatePicker />
  </AppConfigProvider>
</template>
```

未放置 `AppConfigProvider` 时，组件使用 `zh-CN` 默认值，仍可独立工作。

## 业务文案

业务文案不属于组件库职责，应交由应用层的国际化方案管理（如 `vue-i18n`），再通过 props 或插槽传入组件：

```vue
<script setup lang="ts">
import { useI18n } from "vue-i18n";

const { t } = useI18n();
</script>

<template>
  <AppButton>{{ t("actions.submit") }}</AppButton>
  <AppInput :placeholder="t('form.username')" />
</template>
```

这样组件只负责"怎么显示"，"显示什么文字"完全由你的语言包决定。

## 动态切换

把 `locale` 与业务语言包绑定到同一状态，即可实现一键切换：

```ts
function switchLanguage(lang: "zh-CN" | "en-US") {
  locale.value = lang;
  // 同步应用层语言包
  setLocaleMessage(lang, messages[lang]);
}
```

组件内置文案与应用业务文案会同时更新，无需刷新页面。
