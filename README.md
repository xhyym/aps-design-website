# APS Design Website

APS Design Pro 官方组件文档与展示网站，使用 Vue 3、Vite 和 npm 上的 `aps-design-pro` 构建。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建验证

```bash
pnpm build
```

组件文档位于 `docs/`，演示源码位于 `src/demos/`。组件源码与 API 以 [APS Design Pro](https://gitee.com/xhyym/aps-design-pro) 为准。
